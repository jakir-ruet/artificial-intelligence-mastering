### Agentic AI

Its refers to AI systems that autonomously pursue goals by reasoning, planning, using external tools, maintaining memory, and adapting based on observations. Unlike a standalone LLM, an AI agent can perform multi-step workflows and interact with external systems to complete tasks.

#### LLM vs RAG vs Agent

| Capability              |  LLM  |   RAG   | Agent |
| ----------------------- | :---: | :-----: | :---: |
| Generate text           |  Yes  |   Yes   |  Yes  |
| Use external knowledge  |  No   |   Yes   |  Yes  |
| Plan multi-step tasks   |  No   | Limited |  Yes  |
| Use tools               |  No   | Limited |  Yes  |
| Execute actions         |  No   |   No    |  Yes  |
| Maintain workflow state |  No   | Limited |  Yes  |
