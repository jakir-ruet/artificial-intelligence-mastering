### Matplotlib

Matplotlib is an open-source Python library that provides a wide range of tools for creating `static`, `animated`, and `interactive` visualizations such as `line` plots, `bar` `charts`, `histograms`, and `scatter` plots.

👉 In simple terms: Matplotlib = a tool to draw graphs from your data

#### Why it is used

You use Matplotlib to:

- Understand data patterns
- Find trends and relationships
- Present data visually (reports, dashboards)

```bash
pip install matplotlib
```
